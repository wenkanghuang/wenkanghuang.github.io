# 素材管理流程

## 处理边界

原始素材默认从 `E:\BaiduSyncdisk\WenkangHuang` 读取。Codex 可在用户明确指定的范围内整理、筛选、转换和压缩，但不得覆盖、移动或删除原始高清文件，也不得把未确认公开的素材加入 Git。

## 建议流程

1. 用户给出具体原始资料路径和公开范围。
2. 建立待处理清单，区分个人照片、论文、设计、证书和 PDF。
3. 在独立处理目录生成 WebP 或优化后的 PDF，保留原始宽高比与可读性。
4. 对比尺寸、像素、文件大小和视觉质量；记录无法处理的 PSD、AI 等专业源文件。
5. 用户确认裁剪、画质和公开权限。
6. 按稳定 ID 命名后复制到 `assets/`，并更新对应 JSON 路径。
7. 本地预览并检查 404、移动端裁切与详情展示，再提交。

## 图片建议

- 论文/项目封面：建议长边 1600–2400 px，WebP 质量约 82–88，具体以图中文字是否清晰为准。
- 个人照片：保留高质量原件，网页版本建议至少 1200 px 长边。
- 荣誉证书：必须保证文字可读，必要时不压缩或提供可公开 PDF。
- 不拉伸图片；使用 `object-fit: cover` 时应检查主体是否被裁切。
- 不将图片转成 Base64 写入 HTML、CSS 或 JSON。
- 已发表论文的正文主图优先使用出版社公开原图，转换为 WebP、长边控制在约 1400 px，并以正文 Figure 编号命名；默认不处理补充材料图片。
- 图注逐字依据出版社正文记录；若 Early sharing 页面尚未公开图注，只保留可核验的 Figure 编号与来源，不自行补写内容。

## 目录对应

- `assets/profile/`：个人照片与公开简历。
- `assets/papers/`：论文封面、摘要图、公开 PDF 与附件。
- `assets/projects/`：设计项目封面与详情图。
- `assets/awards/`：奖项封面与证书。

## 隐私检查

提交前检查证书编号、身份证件、住址、私人手机号、签名、未公开稿件和其他敏感信息。任何不确定素材默认不公开，并请用户确认。
